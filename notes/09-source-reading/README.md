# 09 · 源码阅读

## 学习目标

按包粒度走读 WeKnora 源码，输出「包地图 + 调用链」两类笔记，为二次开发打底。

## 阅读方法

1. **自顶向下追一条链路**：从 HTTP 路由出发，追到数据库写入，记录每层职责。
2. **看接口不看实现**：先读 interface 定义，理解抽象边界，再挑一个实现细读。
3. **读测试反推契约**：`tests/` 与 `*_test.go` 常比注释更准确。
4. **对照官方文档**：`docs/` 中的设计文档通常解释了「为什么这么设计」。
